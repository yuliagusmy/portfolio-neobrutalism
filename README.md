# Yuliagus M. Yunus - Personal Web Portfolio (Neobrutalism) ⚡

Web portofolio modern dengan estetika **Neobrutalism** (solid black borders, hard unblurred shadows, vibrant high-contrast accents, and tactile responsive interactions), dibangun dengan **Next.js 15**, **Tailwind CSS**, dan **TypeScript**.

## ✨ Fitur Utama
- **Hero & Tentang Saya:** Menampilkan profil, kepribadian ENFJ, peran sosial, dan keahlian utama.
- **Portofolio Desain & Web:** Gallery tipografi dengan rasio 9:16 Instagram Story responsif, filter kategori, dan modal zoom lightbox.
- **Lisensi & Sertifikasi Resmi:** 10 sertifikasi terverifikasi dari Dicoding Indonesia, Coursera, OPSWAT Academy, LinkedIn Learning, dan MySkill dengan tautan verifikasi asli.
- **Artikel / Blog & Kontak:** Kontak langsung terintegrasi dengan WhatsApp, LinkedIn, GitHub, dan Instagram.
- **Responsif & Aksesibel:** Optimal untuk mobile, tablet, hingga desktop dengan rasio skala 90% yang tajam.

## 🛠️ Tech Stack
- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** TypeScript

## 🚀 Menjalankan Secara Lokal

```bash
# Install dependencies
npm install

# Jalankan development server
npm run dev -p 3001
```

Buka [http://localhost:3001](http://localhost:3001) di browser Anda.
