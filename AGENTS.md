# Workspace Instructions for AI Agents

For UI, visual styling, copy, accessibility, responsive design, or code comments in this portfolio project:
1. First read `DESIGN.md` for the product identity, aesthetics, and design direction (Neobrutalism).
2. Then apply `antislop.md` as the quality filter to prevent AI-generated cliches, generic templates, and slop.

## antislop
For UI, copy, people, mobile layout, or code comments work, read `antislop.md` (core) and then the skill for the task:
- UI / visual: `.agents/skills/antislop-ui/SKILL.md`
- Copy & text: `.agents/skills/antislop-copywriting/SKILL.md`
- People: `.agents/skills/antislop-human/SKILL.md`
- Mobile / responsive: `.agents/skills/antislop-layoutmobile/SKILL.md`
- Code comments: `.agents/skills/antislop-code/SKILL.md`
Before starting, ask the user when antislop applies: during the work, or after it is done.
